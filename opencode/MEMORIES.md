# Memories

This file stores persistent memories across sessions. Use `/memorize` to add new memories.

## Categories

- **preference** - User preferences and settings
- **context** - Project context and background
- **decision** - Architecture and design decisions
- **pattern** - Code patterns and conventions
- **warning** - Things to avoid or watch out for
- **workflow** - Process and workflow notes

---

### [workflow] - OpenCode Agent Workflow
> Added: 2025-01-24

Always start in plan mode with Opus for strategic analysis. Use sonnet subagents (@quickfix, @search, @test, @iterate) for fast iterations after planning is complete.
